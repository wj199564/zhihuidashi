# 经典生活问题研究台账

> 状态：检索框架已建立；原文栏必须在本地全文实际读取并核对上下文后填写。禁止凭记忆补录。

## 研究目的

依据项目内收录的五十二部经典，研究用户所述生活困境。证据顺序为：全文原文 → 篇章语境 → 各家义理 → 学派异同 → 针对处境的推演。不得先设计现代方案，再寻找名句背书。

## 原文证据记录格式

每条证据必须记录：

| 字段 | 要求 |
|---|---|
| 议题 | 属于下列九类议题之一，可交叉标注 |
| 书名 | 采用项目目录中的正式名称 |
| 篇章 | 篇名、章次或卷次；无法确定时明确标“待考” |
| 原文 | 保持项目文本原貌，不凭记忆改字 |
| 前文 | 足以判断说话人、对象和问题背景 |
| 后文 | 足以判断结论、条件和可能的转折 |
| 原文所答问题 | 只陈述文本实际处理的问题 |
| 初步义理 | 与原文分开，明确这是解释 |
| 适用边界 | 是否谈修身、政治、养生、出世、用兵等，防止跨域套用 |
| 异文或争议 | 版本、作者、成书年代、篇章真伪等必要说明 |
| 文件位置 | 本地文件路径及行号，供复核 |

## 九类议题与检索口径

### 1. 昏困、睡眠、劳逸与养生

- 核心问题：经典如何理解寝寐、昏沉、劳逸、精气神的消长？是否规定固定睡眠时数？
- 首轮检索词：`寝`、`寐`、`卧`、`睡`、`眠`、`觉`、`旦`、`夜`、`昏`、`困`、`倦`、`劳`、`逸`、`息`、`养生`、`精`、`气`、`神`。
- 防误读：记述圣人作息不等于普遍规范；政治勤勉之辞不直接等于个体养生法。

### 2. 饮食、饱食与食后困倦

- 核心问题：经典如何谈饮食节度、饥饱、滋味对精神和行动的影响？
- 首轮检索词：`食`、`饮`、`饱`、`饥`、`味`、`节`、`腹`、`养`、`谷`、`酒`。
- 防误读：礼制饮食、祭祀饮食、养生饮食应分别处理。

### 3. 打坐、静定及修行成为负担

- 核心问题：儒家的静定、道家的虚静、佛家的禅定分别是什么？着相、执著、昏沉、勉强如何处理？
- 首轮检索词：`静`、`定`、`坐`、`禅`、`念`、`心`、`诚`、`敬`、`虚`、`无住`、`执`、`著`、`相`、`昏沉`、`精进`、`自然`。
- 防误读：不得把儒家“定”、道家“静”、佛家“禅定”视作完全相同；不得把后世固定坐法倒灌进先秦文本。

### 4. 主业、志业、利义与出处进退

- 核心问题：人在生计、职责、功业、求道与个人志向之间如何辨别？谁有权确定其先后？
- 首轮检索词：`志`、`道`、`业`、`事`、`务`、`职`、`位`、`仕`、`隐`、`出处`、`进退`、`义`、`利`、`禄`、`贫`、`达`、`命`。
- 防误读：不得预设主业或梦想必然居先；先区分谋生职责、社会角色、道德之志与个人创作志向。

### 5. 家务、洒扫与环境扰心

- 核心问题：经典如何看待洒扫、整齐、居处、日用之事与修身的关系？
- 首轮检索词：`洒扫`、`应对`、`进退`、`居`、`室`、`庭`、`洁`、`治`、`家`、`日用`、`常`、`物`。
- 防误读：礼仪秩序不直接等于现代洁癖；环境整理与内心修养的关系须由原文证明。

### 6. 忧惧、悔恨、自责与内耗

- 核心问题：经典如何区分正当忧患、反省改过与无益忧惧？如何面对过失而不陷于自我惩罚？
- 首轮检索词：`忧`、`患`、`惧`、`恐`、`悔`、`过`、`改`、`省`、`责`、`耻`、`愧`、`安`、`乐`、`不怨`、`不尤`。
- 防误读：道德反省不能直接等同现代心理学意义的自责；“无忧”也不能简单解释为不处理现实问题。

### 7. 多闻、求知、空谈与躬行

- 核心问题：持续搜索课程和方法究竟属于好学、多闻，还是博而不约、知而不行？经典如何确定学习与行动的关系？
- 首轮检索词：`学`、`问`、`思`、`辨`、`行`、`知`、`闻`、`博`、`约`、`说`、`言`、`躬`、`践`、`习`、`为`。
- 防误读：不同经典对知识、语言和实践的评价不同，不得只选“重行动”的文本压倒全部观点。

### 8. 灵感、欲求、患得患失与无果之惧

- 核心问题：经典如何看待生心、欲望、创造冲动、功利预期、成败得失以及未见结果便不肯行动？
- 首轮检索词：`欲`、`得`、`失`、`成`、`败`、`功`、`名`、`利`、`心`、`意`、`虑`、`谋`、`几`、`时`、`待`、`为`、`无为`。
- 防误读：佛家离相、道家无为、儒家立志、兵家计利各有对象，不能混成“大胆行动”一句话。

### 9. 本末、终始、先后与每日事务次序

- 核心问题：经典提供哪些辨别先后、本末、轻重、缓急的尺度？是否能直接推出一张个人日程表？
- 首轮检索词：`本`、`末`、`终`、`始`、`先`、`后`、`轻`、`重`、`缓`、`急`、`时`、`序`、`节`、`权`、`宜`、`止`、`定`。
- 防误读：经典提供的通常是判断尺度，未必是现代钟点安排；任何具体日程只能标作情境推演，并须由用户确认志向和现实约束。

## 分学派整理要求

每个议题至少检查以下思想群，不以预设结论筛除：

1. 儒家经传及相关文献；
2. 道家及道教相关文献；
3. 佛教经典；
4. 墨家；
5. 法家与《管子》等治术文献；
6. 兵家、纵横家及其他相关诸子；
7. 诗骚等文学经典中可反映生命经验的材料。

若某思想群没有直接证据，应记录“本项目文本中暂未检出”，不得硬凑。

## 最终回答的证据门槛

- 每个核心判断至少有一条直接原文支持；仅有间接材料时必须降格为“可能的推演”。
- 引文必须核对前后文，避免断章取义。
- 不以一句名言代表整部经典或整个学派。
- 对用户生活的具体安排必须保留选择权，并说明还需要用户提供哪些现实条件。
- 现代医学等高风险补充单列，不得混称为经典结论。

# 中国传统经典全文库

本目录用于保存本项目选定经典的可合法再分发之全本原文。

## 收录口径

- “全本”指所选底本的全部正文，不以选段、语录或搜索摘要代替。
- 原书已佚者，收录目前可得的辑佚本全文，并明确标为“现存辑佚本”，不宣称恢复原书。
- 同名而版本差异显著者，必须写明具体版本或译本。例如佛经须注明译者，《坛经》须注明版本系统。
- 正文与后世注疏分开。默认先收无现代译注的古籍原文，避免引入现代版权内容。
- 每部书均须附来源、访问日期、许可或公版判断、目录完整性检查和文件校验值。
- 文本统一保存为 UTF-8；不因简繁转换丢失异体字。首选繁体底本文字，必要时另提供简体派生版。

## 单书目录规范

每部书最终使用一个独立目录：

```text
classics/<编号>-<书名>/
  text.txt       # 全部正文
  metadata.yml   # 版本、来源、许可、字数、校验值
  CHECK.md       # 篇卷目录与完整性核验
```

只有在 `CHECK.md` 中逐篇（或逐卷）核对通过后，才能把总表状态改为“已核验全本”。
